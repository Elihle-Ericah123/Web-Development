CSS PART 2
Part 2 – CSS StylingIn Part 2 I added external CSS to all my pages. I used maroon #7a0000 for the header because it matches the fried chicken brand and looks warm. I used black for the nav bar and white for the links so they are easy to see. I used yellow #ffcc00 for hover and for prices to highlight specials. The background is light cream #fff8f0 for readability.I used Arial font because it is simple and readable on mobile. I made all pages have the same header and nav style to fix the problem from Part 1 where my menu page was purple.I made the site responsive by using 90% width for images and adding padding to text so it does not get cut off on small screens like it did on my About page. I used card layout for the specials with white background, shadow and border to make it look modern. This is one of the current CSS trends.I also added hover effects on the nav links and a moving animation on the Order Now button on the homepage to attract customers. I kept my CSS organized by having a separate CSS file for each page.Feedback Fixes from Part 1I fixed the navigation links that were blue on black and not visible. I changed the menu page header from purple to maroon so all pages match. I fixed the text cut-off on the About page by adding padding. I added alt text to images.
